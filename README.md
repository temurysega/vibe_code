# МГИМО Мания — концепт личного кабинета студента

> **Концепт для конкурса. Не является официальным сервисом МГИМО.** Все люди, оценки, номера зачёток,
> телефоны и адреса почты вымышлены. Знак «МГИМО Мании» — собственный, это не логотип вуза.

**Опубликованный прототип: https://ai.neblanki.tech/**

8 ноября 2026 проверены 117 сценариев и проверок интерфейса на HTTPS-стенде,
реальные ответы OpenRouter для двух студентов и сохранение заявки после перезапуска
контейнера. [Протокол публикации и обновления](docs/DEPLOYMENT.md).

Последняя локальная доработка прошла **35 автоматических тестов и 215 браузерных проверок**
на отдельной базе. Мобильная главная стала компактнее, помощник доступен в шапке,
расписание после завершения недели показывает следующие занятия, а справка о стипендии
содержит шесть месяцев и итог. [Журналы и снимки](docs/evidence/final/run-summary.json).
Добавлены компактный обзор дисциплин на телефоне и фильтр учебных рисков; высота
страницы оценок на проверенных данных сократилась с 4355 до 2936 px.
В 20:28 МСК опубликована версия `review-b27684eaebf8`: 50/50 публичных файлов
совпали с проверенными исходниками, постоянный том и существующие заявки сохранены.
[Протокол обновления](docs/evidence/deployment/review-deployment.json).

Учёба, документы и связь с деканатом — в одном окне, с телефона и компьютера. Под кабинетом —
игровой слой из прототипа «Мании»: аватар и гардероб, питомец, виртуальный кампус вместо офиса
и пятиминутный перерыв-забег. Учебные действия доступны напрямую, независимо от игрового прогресса.

| Расписание | Сегодня и неделя, аудитория с этажом и преподаватель. Отмены, переносы, новые аудитории, замены и доп. занятия подсвечены. Чётность недели, праздники, звонки, экспорт в календарь (.ics) |
| Успеваемость | 100-балльная шкала: баллы по контрольным точкам, прогноз и «сколько не хватает до „отлично“», зона риска, посещаемость, рейтинг в группе, стипендия. Сессия с консультациями и допуском. Электронная зачётка с графиком среднего балла и долгами |
| Заявки и справки | 10 видов справок и заявлений, автозаполнение из профиля, проверка полей, защита от дублей. Статус как у посылки с историей. Электронная справка с кодом проверки подлинности, бумажная — с местом выдачи |
| Уведомления | Новости деканата, изменения расписания, напоминания о дедлайнах за 3 дня, статусы заявок, новые оценки. Фильтры, «прочитать все», живые всплывающие уведомления |

**Сверху — чтобы выделиться**

- **Кабинет деканата** (`dekanat.mo`): очередь заявок своего факультета, решения с комментарием студенту, объявления факультету или группе, отмена пары и смена аудитории, журнал действий.
- **«Спросить деканат»** — помощник по данным самого студента. Поддерживает `OPENROUTER_API_KEY` и прямое подключение Anthropic (вызов только с сервера). Без ключа, при таймауте или ошибке провайдера отвечает по встроенным правилам; источник ответа указан в чате.
- **Кампус** — учебный корпус в разрезе: гардероб, деканат, аудитория, библиотека, студклубы и Лавка. Каждая зона ведёт в раздел кабинета, за прогулку — М-коины и вещи.
- **Аватар, гардероб и питомец** — питомец подсказывает про пару и дедлайн, растёт от фокус-сессий «Учимся вместе 25 минут».
- **Перерыв «Бегом на пару»** — оригинальный раннер по коридору корпуса: три дорожки, прыжок и подкат, кофе и зачётка-бонус. **5 минут в день**, лимит и счёт проверяет сервер.
- **Лавка МГИМО** — мерч за М-коины с цифровой копией для аватара; выдача оформляется заявкой.
- **Первые шаги** первокурсника, квиз, титулы, демо-тур для жюри.

## Запуск

Нужен Node.js 22.13 или новее (используется встроенный `node:sqlite`).

```bash
npm install
npm start
```

Кабинет откроется на http://localhost:3000. Демо-данные создаются при первом запуске и строятся от
текущей даты по Москве: ближайшие переносы, дедлайн послезавтра, справка, которая скоро станет готова.

```bash
npm test
```

Автотесты проверяют изоляцию аккаунтов, безопасность, сохранение данных, основные сценарии и обработку ошибок ИИ. В Windows используйте `npm.cmd test`, если PowerShell запрещает запуск `npm.ps1`.

Проверка интерфейса в Chromium (не требует добавления зависимостей в приложение):

```bash
python -m pip install -r requirements-qa.txt
python -m playwright install chromium
python test/browser-smoke.py http://localhost:3000
python test/browser-flows.py http://localhost:3000
python test/browser-accessibility.py http://localhost:3000
```

Запускайте браузерные сценарии на отдельной тестовой базе: они создают заявки и обрабатывают их в деканате. Скриншоты и протоколы сохраняются в `docs/evidence/`.

### Подключение OpenRouter

Скопируйте `.env.example` в `.env` и заполните **локально**, не публикуя ключ:

```dotenv
OPENROUTER_API_KEY=
OPENROUTER_MODEL=openrouter/free
AI_TIMEOUT_MS=15000
```

После изменения перезапустите сервер. `openrouter/free` — стартовый бесплатный маршрутизатор; можно указать выбранную модель из своего аккаунта. Доступность и лимиты зависят от провайдера. Если заданы оба ключа, приоритет у OpenRouter. Ключи не передаются браузеру, история беседы очищается при выходе. Сервер передаёт провайдеру вопрос и ограниченный снимок вымышленных данных вошедшего студента.

Интеграция использует [официальный Chat Completions API OpenRouter](https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion). Без настоящего ключа тесты проверяют контракт через подмену API; успешность реального запроса нужно проверить отдельно.

### Публикация по ссылке

Для существующего VPS `ai.neblanki.tech`: [конфигурация и порядок обновления](docs/DEPLOYMENT.md).

- **Render**: New → Blueprint → этот репозиторий. `render.yaml` предусматривает **платный** сервис и постоянный диск для SQLite; секрет `OPENROUTER_API_KEY` задаётся в панели. Развёртывание не выполняется автоматически при скачивании проекта. Без постоянного диска Render теряет изменения файлов при перезапуске — [документация](https://render.com/docs/disks).
- **Docker локально**: `docker compose up --build -d`. Откройте http://localhost:3000. Именованный том сохраняет SQLite между перезапусками; `docker compose down` оставляет данные, опция `-v` удаляет их.
- **VPS**: Node.js 24, `npm ci --omit=dev`, постоянный `DB_FILE`, процесс под supervisor и HTTPS-прокси. Для публичного стенда установите `NODE_ENV=production`, `COOKIE_SECURE=1`, `TRUST_PROXY=1` только за доверенным прокси. В Compose порт привязан к localhost для подключения локального HTTPS-прокси.

Автоматический сброс базы по умолчанию отключён (`DEMO_RESEED_HOURS=0`). Команда `npm run seed` **удаляет текущие демо-данные** и создаёт их заново. Для конкурса сохраните стенд до 28 ноября и проверьте URL из России без VPN; наличие конфигурации хостинга не подтверждает доступность.

## Безопасность

- Студент определяется по сессии на сервере, а не по адресу: каждый запрос к заявке проверяет владельца, чужая отвечает 404. Деканат видит только свой факультет.
- Пароли — только хеш scrypt со случайной солью; после 5 ошибок вход блокируется на 15 минут.
- Сеанс — случайный ключ в cookie `HttpOnly; SameSite=Lax; Secure` (префикс `__Host-` в продакшене), в базе — SHA-256 от ключа. Сеансы видны и закрываются в профиле.
- CSRF-токен и проверка Origin для изменяющих запросов, CSP без внешних скриптов, экранирование вывода.
- Ключи сервисов — только в переменных окружения сервера (`.env` в `.gitignore`), в коде и браузере их нет.
- Минимум персональных данных: нет паспорта и СНИЛС, зачётка и телефон скрыты до нажатия, в браузере после выхода ничего не остаётся.

Подробности — в [docs/SECURITY.md](docs/SECURITY.md), устройство — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Стек

Node.js без фреймворков (`node:http`, `node:sqlite`, `node:crypto`, `node:test`), фронтенд на
ES-модулях без сборки. Сейчас это один сервер с файловой SQLite. Для горизонтального масштабирования
потребуются адаптер PostgreSQL, миграции SQL, общие лимиты в Redis и нагрузочная проверка;
одного изменения строки подключения недостаточно.
