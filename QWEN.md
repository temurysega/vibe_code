# QWEN.md — «МГИМО Мания»

Перед любой работой прочитай `AGENTS.md` в корне репозитория: там карта проекта, команды,
инварианты с тестами и формат отчёта. Ниже — самое важное на случай, если `AGENTS.md` не загрузился.

- Студент — только из серверной сессии. Заявка — `WHERE id = ? AND student_id = ?`, чужая → 404 «Заявка не найдена».
- Деканат — только свой факультет; роли разведены на сервере, а не скрытыми кнопками.
- Изменяющие запросы — CSRF и Origin; SQL — плейсхолдеры; вывод — через `esc()`.
- Ключи — только окружение сервера. Значения переменных окружения никогда не выводи.
- После смены аккаунта данные прежнего не остаются: кеши, формы, чат помощника.
- Кабинет работает без внешнего ИИ; резервный ответ не выдавай за ответ модели.
- Только вымышленные данные; маркировка концепта; без логотипа вуза.
- `data/` не очищай и не читай. `npm run seed` и `git push` — только по команде человека.
- Правишь только файлы, перечисленные в задаче. Нужен чужой файл — спроси.
- Прежде чем делать, проверь `rg`-ом, нет ли уже этого в коде. Исправляя поведение, найди все его упоминания.
- Проверка: `npm test`. Отчёт: Сделано / Как проверено / Не проверено / Вопросы.
