# Материалы для отправки

## Комментарий к конкурсной работе

«МГИМО Мания» — конкурсный концепт цифрового деканата. Студент видит ближайшую пару,
понимает учебный риск и получает справку через один кабинет. Все персонажи и учебные
данные вымышлены; проект не является официальным сервисом МГИМО.

**[Открыть прототип](https://ai.neblanki.tech/) · [Исходники](https://github.com/temurysega/vibe_code) · [История создания, PDF](https://github.com/temurysega/vibe_code/blob/main/docs/PROCESS.pdf)**

[Маршрут жюри](https://github.com/temurysega/vibe_code/blob/main/docs/JURY_GUIDE.md)
содержит действия и ожидаемые результаты.
[Текст процесса](https://github.com/temurysega/vibe_code/blob/main/docs/PROCESS.md)
связывает решения, работу с ИИ и проверки.

Главный сценарий: Алина отправляет электронную справку → сотрудник в отдельной сессии
принимает решение → Алина получает уведомление, историю и образец документа.
После входа как Тимур та же ссылка не открывает чужую заявку. Основные действия
доступны на экране от 360 px. Кампус и питомец дополняют кабинет; играть для учёбы не нужно.

Claude и Qwen использованы через терминал для разработки; Codex и субагенты — для
проверки, доработок и материалов. Четыре предоставленных автором скриншота реальных
диалогов связаны с функциями продукта. Отдельно показаны поручения агентам, найденные
ошибки и исправления. Шесть подробных карточек заданий честно обозначены как реконструкции.

По словам автора, кабинет попробовали два студента: назначение понятно, но первое
действие нашли не сразу; оба разобрались. По этой обратной связи реализована кнопка
«С чего начать»: диалог ведёт к расписанию, оценкам и справкам. Эти действия появились
и при первом знакомстве. Повторной проверки со студентами после изменений пока нет.

Результаты проверок собраны в [аудите](https://github.com/temurysega/vibe_code/blob/main/docs/CONTEST_AUDIT.md):
локальные запуски и проверки опубликованной версии имеют отдельные даты и протоколы.
Помощник обращается к модели с сервера; при сбое работают встроенные правила.
Видео не прилагается: по условиям оно необязательно.
