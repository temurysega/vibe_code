**«МГИМО Мания» — концепт цифрового деканата.** Студент сразу видит ближайшую пару
и изменения в расписании, понимает, сколько баллов не хватает до зачёта или «отлично»,
и получает справку онлайн: заявка проходит через сотрудника деканата, а результат
возвращается уведомлением и документом с кодом проверки. Все люди и данные вымышлены;
это конкурсный концепт, а не официальный сервис МГИМО.

- **Прототип:** https://ai.neblanki.tech/
- **Исходный код:** https://github.com/temurysega/vibe_code
- **Описание процесса (PDF):** https://github.com/temurysega/vibe_code/blob/main/docs/PROCESS.pdf
- **Маршрут для жюри:** https://github.com/temurysega/vibe_code/blob/main/docs/JURY_GUIDE.md

**Главный сценарий:** Алина отправляет электронную справку → сотрудник деканата в приватном
окне или другом профиле браузера берёт её в работу и отмечает готовность → Алина получает уведомление, историю
и образец документа с кодом проверки. Ссылка на заявку Алины у Тимура показывает
«Заявка не найдена». Всё работает и на телефоне от 360 px. Кампус, питомец и игра —
необязательный слой: для учёбы играть не нужно.

**Как создавался:** код написали ИИ-ассистенты — Claude Code (модель Claude Opus 5.5)
собрал кабинет по тексту задания, Qwen Code использовался в разработке, Codex с субагентами
провёл аудит по критериям, исправления, браузерные проверки и публикацию. Для агентов
написан `AGENTS.md` с инвариантами безопасности; найденные ошибки закреплены регрессионными
тестами. Промпты, ошибки ИИ и исправления — в PDF.

**Обратная связь:** кабинет попробовали два студента — назначение было понятно, но первое
действие нашли не сразу. По этому замечанию появилась кнопка «С чего начать» с тремя
учебными действиями.
