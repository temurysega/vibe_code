## П-30 · Первая публикация на VPS с сохранением данных

> - **Кому:** Codex или Claude Code; выполнение — субагент `release-engineer`, только по команде
> - **Опирается на:** ADR-002, ADR-008, `docs/SECURITY.md`
> - **Приёмы:** подготовка отделена от выполнения · план отката до выкладки · секреты не выводятся никогда · что проверяют только люди — названо явно

```text
Готовим публикацию на наш VPS под адресом ai.neblanki.tech. Там уже работает Caddy и несколько
других контейнеров. Требования конкурса: кабинет открывается по ссылке из России без VPN и работает
до 28 ноября.

Подготовь, но не выполняй на сервере:
1. Dockerfile: Node.js 24, npm ci --omit=dev, запуск от непривилегированного пользователя; в образ
   попадают только runtime-файлы — без docs/, test/, data/ и .env.
2. deploy/compose.vps.yaml: контейнер в той же Docker-сети, что и Caddy; порт на хосте привязан
   только к 127.0.0.1; именованный том для SQLite (DB_FILE на томе); переменные NODE_ENV=production,
   COOKIE_SECURE=1, TRUST_PROXY=1 (только потому, что впереди наш Caddy), DEMO_RESEED_HOURS=0;
   секреты — из существующего env-файла на сервере; ограничение размера логов.
3. deploy/ai.neblanki.tech.caddy: только блок нашего домена — HTTPS, сжатие, проксирование на
   сервис по имени в общей сети. Остальные хосты в общем Caddyfile не трогаем. Заголовки
   безопасности уже ставит приложение — не дублируй их противоречиво.
4. docs/DEPLOYMENT.md: порядок обновления и отката.

План выкладки пришли мне до выполнения: резервная копия базы и PRAGMA integrity_check; какие
контейнеры заменяем; ID и время запуска соседних контейнеров до и после (они не должны измениться);
как откатываемся (предыдущий образ + копия базы). Значения секретов никогда не выводи — ни
в терминал, ни в протокол.

После моего «да» и выкладки:
- приёмка HTTPS-версии на 360 и 1366 px: вход и выход всех ролей, учебные разделы, чужая заявка →
  «Заявка не найдена», смена аккаунта между вкладками. На публичном стенде не создавай объявлений
  и решений деканата; одну проверочную заявку можно создать и затем отменить;
- сохранение: проверочная заявка и сессия переживают перезапуск контейнера;
- протокол в docs/evidence/deployment/<папка>/ без секретов: версия, хеш, результаты.

Отдельно перечисли, что можем проверить только мы, люди: открытие с мобильного интернета в России
без VPN, оплата VPS и срок сертификата до 28 ноября.
```

**Если ИИ ошибся**
- Выводит переменные окружения «для диагностики»: «Остановись. Значения секретов не выводим никогда.
  Проверяй наличие переменной (задана / не задана), а не её значение».
- Предлагает бесплатный хостинг без постоянного диска: «Без постоянного диска база теряется при
  перезапуске (по документации Render файловая система сервиса без диска временная; при подготовке
  методички это не перепроверялось). Либо план с диском, либо наш VPS с томом».
- После выкладки у вернувшихся посетителей старый сайт: промпт О-10.

**В репозитории:** `Dockerfile`, `compose.yaml`, `deploy/compose.vps.yaml`,
`deploy/ai.neblanki.tech.caddy`, `render.yaml` (`plan: starter` с диском), `docs/DEPLOYMENT.md`;
коммиты `969bdf4`, `2e48826`; протоколы — `docs/evidence/deployment/`.

## П-31 · Повторная выкладка: тот же код, что прошёл проверку

> - **Кому:** субагент `release-engineer`, по команде человека
> - **Приёмы:** сверка хешей проверенного и выкладываемого кода · публичная приёмка без создания данных · новые протоколы не затирают старые

```text
Выкладываем версию, которая прошла общий прогон docs/evidence/<папка>/run-summary.json.

1. Сверь: хеши исходников в run-summary совпадают с тем, что ты упакуешь. Если нет — остановись:
   мы проверили не тот код.
2. Упакуй только runtime-файлы и сравни список с прошлой выкладкой.
3. Дальше — по docs/DEPLOYMENT.md: копия базы и integrity_check, замена контейнера с тем же томом,
   healthcheck, соседние контейнеры без изменений.
4. Публичная приёмка на HTTPS (браузерные наборы) — только вход и выход, без создания данных.
5. Протокол — в новую папку docs/evidence/deployment/…; старые протоколы не трогай.

В отчёте: версия и хеш, результаты приёмки, что сохранилось из прежних данных, что не проверялось.
```

**В репозитории:** публикация 9 ноября — версия `3b722e9`, совпадение 52 публичных файлов,
сохранность прежних заявок и сеансов, публичная приёмка 25/25 (`c13d305`,
`docs/evidence/deployment/quality-fixes-deployment.json`).
