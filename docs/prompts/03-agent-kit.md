# 03 · Комплект файлов для ИИ-агентов

> **Происхождение.** Методичка написана после создания прототипа по его коду, журналам и истории Git. Это не журнал промптов. Настоящие диалоги — [`docs/ai/PROMPTS_LOG.md`](../ai/PROMPTS_LOG.md) и [`docs/evidence/subagents-2026-11-19/`](../evidence/subagents-2026-11-19/).

**Цель этапа:** до первой строки кода дать всем агентам одну версию правды о проекте.
**Шлюз на выходе:** комплект лежит в репозитории, и пробный прогон агента на маленькой задаче
показал, что ему хватает информации.

С «МГИМО Манией» работали Claude Code и Codex; комплект рассчитан и на Qwen Code. Если у
каждого инструмента свой контекст, они по-разному понимают одни и те же правила. Поэтому главный файл один — `AGENTS.md`.
Codex читает его сам, Claude Code подключает через `CLAUDE.md` (строка `@AGENTS.md`), а Qwen Code
получает короткий `QWEN.md` со ссылкой на него и копией критичных инвариантов.

Готовые файлы уже лежат в корне репозитория: [`AGENTS.md`](../../AGENTS.md), [`CLAUDE.md`](../../CLAUDE.md),
[`QWEN.md`](../../QWEN.md), [`.claude/`](../../.claude/), [`docs/ai/`](../ai/). Для другого проекта их
можно скопировать оттуда. Папка `.claude/` скрытая: в Finder её показывает `Cmd + Shift + .`.

## П-09 · Собери комплект для агентов

> - **Кому:** Claude Code
> - **Опирается на:** `PRODUCT.md`, `SPEC.md`, `DECISIONS.md`, модель угроз из П-08
> - **Даёт:** `AGENTS.md`, `CLAUDE.md`, `QWEN.md`, `.claude/agents/*`, `.claude/commands/*`, `.claude/settings.json`, `docs/ai/*`
> - **Приёмы:** один источник правды для трёх инструментов · узкие роли субагентов · пробный прогон комплекта на задаче

```text
Над проектом будут работать три агента: ты (Claude Code — основная разработка), Codex (аудит и
параллельные доработки с субагентами) и Qwen Code (отдельные модули из терминала). У всех должна
быть одна версия правды о проекте, иначе каждый будет восстанавливать контекст по-своему.

Собери комплект:
1. AGENTS.md в корне — главный файл. Его читают Codex и Qwen Code, а CLAUDE.md подключает его через
   @AGENTS.md. Не длиннее 150 строк: карта каталогов; команды; нумерованные инварианты (возьми из
   модели угроз и SPEC.md); Definition of Done; правила параллельной работы и владения файлами;
   правила документирования («только наблюдаемые факты»); необратимые действия только по команде
   человека; формат отчёта.
2. CLAUDE.md — @AGENTS.md плюс то, что касается только Claude Code: план-режим для задач больше трёх
   файлов, проверка во встроенном браузере на 360 и 1366 px, какие субагенты вызывать, обновление
   PROGRESS.md в конце сессии.
3. QWEN.md — короткая отсылка к AGENTS.md и копия критичных инвариантов на случай, если файл по
   ссылке не будет прочитан.
4. .claude/agents/ — шесть субагентов с узкими ролями: security-auditor, ui-mobile-reviewer,
   test-engineer, content-writer, docs-chronicler, release-engineer. У каждого: когда его вызывать,
   какие инструменты разрешены, что он делает по шагам, формат результата и чего он не делает.
   Аудиторы только читают и запускают проверки — правки делает основной агент.
5. .claude/commands/ — /feature, /bugfix, /verify: процессы, которые мы будем повторять много раз.
6. .claude/settings.json — запрет читать .env и data/; подтверждение человека для git push,
   npm run seed, docker и ssh.
7. docs/ai/ — PRODUCT.md, SPEC.md (уже есть), DESIGN.md, DECISIONS.md, PROGRESS.md, ERRORS.md,
   PROMPTS_LOG.md.

Пиши для агента, а не для человека: короткие утверждения, конкретные пути и команды, никаких общих
слов вроде «пиши качественный код».

Когда закончишь, проверь комплект на себе: возьми задачу «добавить в профиль куратора группы» и
перечисли, какие файлы ты прочитаешь, какие инварианты к ней относятся, какую команду вызовешь и чем
закончишь. Если для ответа чего-то не хватило — допиши комплект.
```

**Если ИИ ошибся**
- AGENTS.md на 400 строк с пересказом всего проекта: «Агенты читают этот файл в каждой сессии.
  Оставь только то, без чего агент ошибётся; подробности вынеси ссылками в docs/ai/».
- Субагент с ролью «улучшай всё»: «У каждого субагента одно направление и формат результата.
  Аудитор не правит код — он присылает таблицу находок».

## Как комплект живёт

- **Начало сессии:** агент читает `AGENTS.md` и `PROGRESS.md`, пересказывает, где мы, и только
  после подтверждения начинает работу (промпт О-8 в [07-ai-errors.md](07-ai-errors.md)).
- **Во время работы:** повторяющиеся процессы запускаем командами `/feature`, `/bugfix`, `/verify`,
  а не пишем каждый раз заново.
- **Ошибка:** запись в `ERRORS.md`. Если это класс ошибок — новое правило в `AGENTS.md`. Например,
  инвариант 7 о смене аккаунта закрепляет урок ошибки с кешем профиля (E-01), а правило «исправляя
  поведение, найди все его упоминания» — урок недоделанного исправления псевдо-QR (E-34; исправлено 19 ноября, `fe1191c`).
- **Конец сессии:** `PROGRESS.md` и `PROMPTS_LOG.md` обновлены, коммит после шлюза. Тогда история
  Git становится настоящей хронологией работы.

**В репозитории:** `AGENTS.md` появился 8 ноября (`00882b7`), на этапе аудита, в краткой версии с шестью
инвариантами. Расширенный комплект (`CLAUDE.md`, `QWEN.md`, `.claude/`, `docs/ai/`) добавлен позже, при
подготовке итоговой версии. В методичке комплект идёт до кода: тогда первая версия собирается уже по
инвариантам, а не исправляется под них позже.
