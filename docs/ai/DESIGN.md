# DESIGN.md — визуальный язык «МГИМО Мании» (для агентов)

Источник значений — `public/css/tokens.css`. Здесь роли токенов и правила применения. Значения ниже сверены с файлом 19 ноября.

## Палитра и роли
| Токен | Значение | Роль |
|---|---|---|
| `--navy` | `#0F2D69` | основной цвет: главные кнопки, активное меню, знак |
| `--navy-2` | `#1C438F` | наведение, вторичные акценты |
| `--navy-3`, `--navy-4` | `#DCE6F8`, `#EEF3FC` | фоны выделения |
| `--gold` | `#C9A646` | акцент: награды, подсветка демо-тура. **Не для текста на белом** |
| `--gold-ink` | `#7A5F12` | текст на золотых фонах |
| `--ink`, `--text` | `#1B1F2A`, `#2E3440` | заголовки и основной текст |
| `--muted`, `--muted-2` | `#5F6673`, `#626978` | второстепенный текст |
| `--bg`, `--surface`, `--surface-2` | `#FFFFFF`, `#F3F4F6`, `#E8EAED` | фон, карточки, вложенные поверхности |
| `--border`, `--hair` | `#DEDFE1`, `#ECEDEF` | границы и разделители |
| `--good` / `--good-2` | `#257132` / `#E6F4E8` | «в порядке»: текст / фон |
| `--warn` / `--warn-2` | `#925600` / `#FFF1DC` | «внимание»: текст / фон |
| `--red-ink` / `--red-2` | `#B3261E` / `#FDECEC` | «риск» и ошибки: текст / фон |
| `--violet`, `--blue`, `--mint` (+ `-2`, `-ink`) | см. файл | категории: виды занятий, типы уведомлений |

Правило: цветной текст — только `*-ink`, `--good`, `--warn`; светлые варианты `*-2` — только фоны.
Контраст текста на фоне проверяет `test/browser-focus-contrast.py` (E-30). Новые цвета — только через токен.

## Форма
Радиусы `--r-sm` 12, `--r` 16, `--r-lg` 24 px; кнопки — «таблетки» (`--pill`). Тени: `--shadow` для карточек,
`--shadow-lg` для диалогов. Контейнер 1240 px, шапка 72 px, полоса концепта 34 px.

## Шрифт
Onest (SIL OFL 1.1), локально из `public/fonts/` вместе с лицензией `OFL-Onest.txt`; запасной — системный.
Внешние шрифты и CDN запрещены: CSP: `default-src 'self'`, `font-src 'self'` (`server/security/headers.js`); стили допускают `'unsafe-inline'`.

## Компоненты
- **Карточка:** фон `--surface`, радиус 16; заголовок → главный факт или цифра → действие.
- **Кнопки:** primary (`--navy`), secondary, ghost. Область нажатия кнопок и фильтров не меньше 44 px по высоте.
  Мелкие ссылки получают невидимую область нажатия 34–45 px без сдвига вёрстки (E-15); тест `browser-audit-fixes.py`
  требует не меньше 32 px.
- **Поле:** подпись над полем; ошибка — текстом под полем (`.field.invalid`); при отправке фокус переходит к первому
  ошибочному полю, введённое не теряется (`public/js/views/requests.js`).
- **Чипы-фильтры:** `aria-pressed`, число результатов в подписи; фокус сохраняется при смене фильтра (E-29).
- **Нижнее меню (телефон):** Главная, Расписание, Оценки, Заявки, «Ещё»; подписи 12 px (`public/css/responsive.css`).
- **Шапка (компьютер):** Главная, Расписание, Успеваемость, Заявки + кнопка «Студенческая жизнь» (кампус, гардероб, Лавка, перерыв).
- **Диалог** (`public/js/ui/overlay.js`): удерживает фокус, закрывается по Escape, возвращает фокус на кнопку вызова.
- **Полоса концепта:** на экранах кабинета — «Концепт для конкурса · не официальный сервис МГИМО · все люди и данные вымышлены»;
  кнопка «Демо-тур» показывается после входа (`paintConcept` в `public/js/app.js`).

## Состояния — обязательны для каждого экрана с данными
- Загрузка — скелет, а не пустота.
- Пусто — что это значит и что можно сделать.
- Ошибка — что случилось и «Повторить», которое действительно запрашивает данные заново (E-06; `test/browser-accessibility.py`, ответ 503).
- Успех — подтверждение и следующий шаг.

## Телефон, 360 px
- Нет горизонтальной прокрутки страницы.
- Главное действие экрана — в первом экране, над нижним меню (E-32).
- Длинные списки — порциями с «Показать ещё» (E-16: лента уведомлений по 12 карточек).
- Второстепенное сворачивается и раскрывается по нажатию и с клавиатуры.
- Игровой блок на главной — ниже учебного.

## Движение
Анимации короткие; `prefers-reduced-motion` отключает их (`public/css/effects.css`). Обновление данных не сбрасывает фокус
и не пересоздаёт элемент, на котором стоит фокус: устойчивый ключ `data-focus-key` (E-28, E-31, E-33).

## Не делай
Новые цвета вне токенов · внешние шрифты и CDN · статус только цветом · текст `--gold` на белом ·
кнопка-иконка без доступного названия · «Повторить», который ничего не делает ·
декоративный узор, похожий на QR-код, и текст про QR, пока QR в продукте нет (E-07, E-34).
