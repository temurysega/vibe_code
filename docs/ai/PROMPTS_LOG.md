# PROMPTS_LOG.md — журнал промптов

Записываем каждый промпт, после которого изменился код или документ, — дословно и без секретов.
Поручения агента субагентам записываем туда же с пометкой «поручение агента».
Запись без проверяемого источника не добавляем: если оригинала нет, пишем «не сохранился».

## Формат записи
```
## <дата МСК> · <короткое название>
- Инструмент и модель: <Claude Code (…), Codex, Qwen Code, …>
- Кто ставит задачу: <человек | поручение агента → субагенту «…»>
- Происхождение текста: оригинал (файл) | выдержка | пересказ | реконструкция
- Промпт:
  > <дословный текст>
- Что получилось: <1–3 предложения>
- Проверка: <команда → результат; сценарий → результат>
- Коммиты: <хеши>
- Что пошло не так: <ссылка на E-NN в ERRORS.md>
```
