**Прототип:** https://ai.neblanki.tech/ · **Исходники:** https://github.com/temurysega/vibe_code ·

## Обязательное ядро

| Раздел | Что реализовано | Где в коде | Как проверить |
|---|---|---|---|
| Вход и профиль | Логин и пароль, демо-аккаунты одним нажатием, блокировка перебора, активные сеансы. Профиль: ФИО, факультет, направление, профиль, курс, группа, языки, куратор, контакты деканата | `server/routes/auth.js`, `student.js`, `public/js/views/profile.js` | Войти как `a.morozova`, открыть профиль |
| Расписание | Сегодня и неделя, аудитория с этажом, преподаватель; отмены, переносы, новые аудитории, замены и доп. занятия выделены; чётность недели, звонки, экспорт в календарь | `server/domain/schedule.js`, `public/js/views/schedule.js` | У Алины — блок «Изменения на неделе» и отметки в днях |
| Успеваемость | 100-балльная шкала, контрольные точки, прогноз, «сколько не хватает», зона риска, сессия с допуском, зачётка с долгами | `server/domain/grades.js`, `public/js/views/grades.js` | Фильтр «Требуют внимания» у Алины; долг и пересдача у Ксении |
| Заявки и справки | 10 видов, автозаполнение из профиля, серверная проверка полей, защита от дублей, статус с историей, решение сотрудника, электронный образец с кодом проверки | `server/domain/requests.js`, `routes/requests.js`, `routes/dean.js` | Маршрут жюри: Алина → деканат → документ |
| Уведомления | Новости деканата, изменения расписания, напоминания о дедлайнах за 3 дня, статусы заявок, новые оценки; фильтры и «прочитать все» | `server/domain/notifications.js`, `public/js/views/notifications.js` | Уведомление о готовой справке ведёт к заявке |

Сверх ядра: кабинет сотрудника деканата, помощник «Спросить деканат» по данным студента
(OpenRouter с сервера, при сбое — встроенные правила), необязательный игровой слой
(кампус, питомец, перерыв-забег) и проверка подлинности справки по коду без входа.

## Требования к прототипу

| Требование | Как выполнено | Подтверждение |
|---|---|---|
| Работающий прототип по ссылке | HTTPS-стенд, по нему проходятся вход, расписание, оценки, подача заявки и её статус | [Маршрут жюри](JURY_GUIDE.md), браузерные сценарии `test/browser-*.py` |
| Стек и масштабирование | Node.js без фреймворков и SQLite; путь к нескольким экземплярам описан | [ARCHITECTURE.md](ARCHITECTURE.md) |
| Код пишут ИИ-ассистенты | Claude Code, Qwen Code, Codex с субагентами; инструкции для агентов в `AGENTS.md` | [PROCESS.md](PROCESS.md), разделы 2–3 и 9 |
| Мобильная версия от 360 px | Все основные сценарии проверены на 360 и 1366 px | Таблица проверок ниже |
| Студент видит только свои данные | Студент определяется сессией; заявка ищется по `id` и владельцу, чужая — 404 «Заявка не найдена»; деканат ограничен своим факультетом | `test/security.test.js`, `browser-flows.py`, [SECURITY.md](SECURITY.md) |
| Пароли не хранятся открыто | scrypt со случайной солью, сравнение за постоянное время | `server/security/password.js`, тест хеширования |
| Ключи не в коде и не в браузере | Только переменные окружения сервера; `.env` исключён из Git, образа и архива | Тест «ключ ИИ не уходит в браузер» |
| Только вымышленные данные | Все люди, оценки, номера и документы созданы в `server/seed/`; реальные системы вуза не подключены | Исходники сида |
| Не выдаётся за официальный сервис | Полоса «Концепт для конкурса» на каждой странице, подвал, пометка на образце справки | Любой экран кабинета |
| Без логотипа вуза | Собственный SVG-знак проекта | `public/img/logo.svg`, `public/js/art/logo.js` |
| Сторонние материалы | Шрифт Onest (SIL OFL 1.1) хранится локально с лицензией; лицензии зависимостей перечислены | [THIRD_PARTY.md](../THIRD_PARTY.md) |
| Данные сохраняются | SQLite в постоянном томе, автосброс отключён; заявка переживает перезапуск контейнера | `backend-regressions.test.js`, [проверка на стенде](evidence/deployment/production-persistence.json) |

## Границы проверки

- Полный аудит доступности по WCAG и нагрузочное тестирование не проводились.
- Обратная связь двух студентов качественная; замеров времени и повторной проверки
  после доработки нет. План такой проверки — в разделе 1 [PROCESS.md](PROCESS.md).
- Живые ответы ИИ проверены на конкретных запросах; точность любых ответов модели
  не гарантируется. При сбое провайдера помощник отвечает по встроенным правилам.
- Тестовые аккаунты общие для всех экспертов: в них могут быть заявки и объявления
  других проверяющих. Публикации деканата ограничены 10 за 10 минут.
