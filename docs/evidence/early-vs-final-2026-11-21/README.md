# Ранняя и итоговая версии на одинаковых кадрах

**Что это.** Снимки сделаны 21 ноября в 20:13 МСК, обе версии — на свежих временных базах и одинаковых кадрах.
«Ранняя» — код коммита `4f1e623`, последнего из коммитов 4 ноября, то есть состояние после первой сессии.
Это **повторный запуск того кода 21 ноября**, а не снимок, сделанный 4 ноября: снимков экрана того дня нет.
Демо-данные в обеих версиях создаются от текущей даты, поэтому даты на экранах — 21 ноября.
«Итоговая» — коммит, указанный в `final.json` (21 ноября). 22 ноября страница входа изменилась: тестовые аккаунты
стоят перед формой (E-44); вход на телефоне после этого — `../ios-simulator-2026-11-22/02-login-after-fix.png`.

Что видно на кадрах:
- **Вход на телефоне.** 4 ноября плашки на обложке наезжали на подзаголовок, а иллюстрация опускала форму,
  и тестовые аккаунты оставались ниже первого экрана. В итоговой версии форма и первый тестовый аккаунт
  видны сразу: плашки исправлены после аудита 9 ноября, первый экран — по находке независимого аудита
  19 ноября (П-28, коммит `c8955dc`).
- **Главная на телефоне.** 4 ноября первый экран целиком занимала карточка ближайшей пары. В итоговой —
  компактная карточка пары, затем «Требует внимания» (дисциплина в зоне риска) и «Готова» (справка),
  а пары дня свёрнуты в одну строку.

Как повторить:

```
git worktree add --detach <временная папка> 4f1e623
# в этой папке: node server/index.js с DB_FILE=<временный файл>, PORT=3500, COOKIE_SECURE=0, ключи ИИ пустые
python scripts/shoot-version.py http://127.0.0.1:3500 docs/evidence/early-vs-final-2026-11-21 early-2026-11-04 4f1e623
# итоговая версия — так же из основной папки на другом порту, метка final
```

Для запуска старого кода использовалась папка `node_modules` текущей версии: в `package.json` 4 ноября
единственная зависимость — `@anthropic-ai/sdk`, а внешний ИИ при съёмке выключен.
