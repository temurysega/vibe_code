# Повторный замер: те же задания у пятерых участников опроса

**Откуда данные.** 22 ноября автор передал ту же таблицу ответов, что и для [опроса 25 студентов](../survey-2026-11-22/),
с двумя новыми столбцами — повторные ответы на два вопроса о заданиях в кабинете: «Насколько легко было выполнить
задания с телефона?» и «Какое задание было самым трудным?». Слова автора: «добавилось 2 столбца с повторными замерами».
Повторные ответы есть у 5 из 25 участников — строки 2, 5, 10, 13 и 15. Ответы исходного замера в таблице
не изменились: первые 11 столбцов совпадают с прежней копией байт в байт.

Отметок времени, имён и описания условий в таблице нет: дату повторного прохождения, сборку кабинета и устройство
по таблице не установить. [responses.csv](responses.csv) — копия таблицы: пустой столбец времени заменён номером
строки, из заголовков убраны лишние пробелы. Числа — [repeat.json](repeat.json); пересчитать:

```
python scripts/survey-repeat.py docs/evidence/survey-repeat-2026-11-22
```

## Две группы

| | Исходный замер | Повторный замер |
|---|---|---|
| Участников | 25 | 5 — из тех же 25 |
| Лёгкость заданий с телефона, самооценка от 1 до 5 | среднее 4,4, медиана 5 | у этих пятерых было 3,2, стало 4,4 |
| «Все задания были лёгкими» | 16 из 25 | у пятерых было 1, стало 3 |
| Самым трудным назвали | риск по дисциплине — 3, перенос пары — 3, заказ справки — 2, найти документ — 1 | было: заказ справки — 2, риск по дисциплине — 1, найти документ — 1; стало: заказ справки — 1, найти документ — 1 |

## Каждый участник

| Строка | Лёгкость: было → стало | Самое трудное: было → стало |
|---|---|---|
| 2 | 4 → 5 | все были лёгкими → все были лёгкими |
| 5 | 3 → 4 | найти документ → найти документ |
| 10 | 3 → 4 | риск по дисциплине → все были лёгкими |
| 13 | 4 → 5 | заказ справки → все были лёгкими |
| 15 | 2 → 4 | заказ справки → заказ справки |

## Фактическая разница

- У тех же пяти человек самооценка лёгкости выросла в среднем на 1,2 балла: с 3,2 до 4,4, у каждого на 1 или 2.
- Средние двух групп напрямую не сравниваются. 4,4 исходного замера — среднее по 25 участникам, 4,4 повторного —
  по пяти, которые в исходном замере оценили задания ниже остальных: у них было 3,2, у двадцати не повторявших — 4,7.
  Из четырёх участников, поставивших в исходном замере 3 и ниже, в пятёрку попали трое.
- Риск по дисциплине — задание, к которому относится правка главной по итогам опроса (`4209326`, причина риска
  прямо в ярлыке). В пятёрке его называл самым трудным один человек; в повторном замере он ответил «все были лёгкими».
  Перенос пары никто из пятерых самым трудным не называл ни разу.
- Трудными остались «найти документ» (строка 5) и «заказ справки» (строка 15) — следующие кандидаты на доработку.

## Чего повторный замер не показывает

- Это самооценка, а не время выполнения и не успех по каждому заданию.
- Задания проходили второй раз: часть роста может дать привыкание к кабинету.
- Пятёрку отбирали не случайно; низкие исходные оценки при повторе склонны расти и без изменений интерфейса.
- На какой сборке повторяли задания, в таблице не записано. Стенд `ai.neblanki.tech` 22 ноября ещё работал
  на версии 19 ноября; правка главной `4209326` есть только в репозитории и локальном запуске.
- Пять ответов — слишком мало для вывода о всех студентах.
