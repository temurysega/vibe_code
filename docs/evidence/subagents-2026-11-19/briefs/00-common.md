## Правила
1. Ты работаешь параллельно с другими агентами. Меняешь **только свои файлы** из поручения.
   Если нужен чужой файл — не трогай его, а напиши в отчёте, что и зачем изменить.
2. Не делай: `git commit`, `git push`, публикацию на сервер, `ssh`, `npm run seed`, удаление файлов
   вне своей зоны. Коммиты делает основной агент.
3. Не читай `.env` и `data/`. База для проверок — только временная: `DB_FILE` во временной папке,
   `OPENROUTER_API_KEY=` и `ANTHROPIC_API_KEY=` пустые. Не входи паролями на публичный стенд
   https://ai.neblanki.tech — только на локальный сервер.
4. Факт, слова автора и реконструкция — разные вещи. Пиши только то, что проверил; непроверенное
   перечисли отдельно. Не выдумывай даты, коммиты, числа и названия файлов: каждое утверждение о
   репозитории должно подтверждаться файлом, тестом или `git log`.
5. Пиши по-русски, коротко и конкретно, с путями к файлам.
6. Отчёт в конце: **Сделано / Как проверено (команда → результат) / Не проверено / Предложения
   основному агенту**.
