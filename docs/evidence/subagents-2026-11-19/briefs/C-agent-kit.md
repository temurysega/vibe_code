# Поручение C · промпт П-09 «Собери комплект для агентов» — по-настоящему, в репозиторий

Сначала прочитай общие правила:
`<scratchpad>\sonnet\briefs\00-common.md`.

**Роль:** комплект файлов для ИИ-агентов. **Твои файлы:** `AGENTS.md`, `CLAUDE.md`, `QWEN.md`,
`.claude/agents/*.md`, `.claude/commands/*.md`, `.claude/settings.json`, `docs/ai/*.md`.
Остальное только читаешь. Особенно не трогай `public/js/shared/catalog.js` и `test/` — там сейчас
работает другой агент.

**Промпт из методички (дословно — `03-agent-kit.md`, П-09):** прочитай его целиком в файле
`...\prmt-src\x\03-agent-kit.md`, раздел «П-09 · Собери комплект для агентов», и выполни.

**Исходный материал:** готовый черновик комплекта лежит в `...\prmt-src\x\agent-kit\` (19 файлов).
Он написан после создания проекта и местами расходится с репозиторием. Задача — не скопировать, а
**перенести и сверить**:

1. Каждый путь, команда, имя теста, коммит и инвариант в комплекте должны существовать в текущем
   репозитории (`git log`, `ls`, чтение кода). Ссылки на несуществующие файлы (например, `docs/ai/SPEC.md`)
   либо создай настоящим файлом, либо убери. `docs/ai/SPEC.md` полезен: нумерованные требования
   конкурса → где реализовано → как проверить (основа — `docs/CONTEST_AUDIT.md` и тесты).
2. `AGENTS.md` — объединить нынешний `AGENTS.md` репозитория (его шесть инвариантов остаются) и версию
   из комплекта. Не длиннее 150 строк. Каждый инвариант должен подтверждаться кодом или тестом —
   укажи тест рядом.
3. `docs/ai/ERRORS.md` — у каждой записи должен быть проверяемый источник в репозитории: коммит,
   тест, файл в `docs/evidence/`. Если источника нет — пометь «со слов автора» или убери.
   **Исправь E-11:** в черновике сказано, что агент «подписал четыре настоящих скриншота диалогов как
   реконструкции». Это неверно. На самом деле четыре изображения в `docs/evidence/dialogue-illustrations/`
   созданы ChatGPT (в PNG есть метаданные C2PA: ChatGPT, gpt-image, trainedAlgorithmicMedia,
   8 ноября 20:11–20:15 МСК) и в документах были подписаны как скриншоты переписки. Это заметил
   независимый аудит 9 ноября по метаданным; 18 ноября иллюстрации заменяются настоящими диалогами
   субагентов. Запиши именно так. Добавь E-34: в квизе «Первые шаги» осталось обещание QR-кода
   (`public/js/shared/catalog.js`), исправление выполняет поручение A 18 ноября — пометь «в работе»,
   основной агент обновит статус.
4. `docs/ai/PROGRESS.md` — состояние на 18 ноября по фактам репозитория.
   `docs/ai/PROMPTS_LOG.md` — формат из черновика и записи только с проверяемым происхождением:
   три настоящие короткие просьбы автора (найди их дословно в `docs/evidence/*-session.json`, укажи
   файл) и раздел «18 ноября 2026», куда основной агент допишет поручения субагентам.
   `docs/ai/PRODUCT.md`, `DESIGN.md`, `DECISIONS.md` — сверь с кодом, исправь расхождения.
5. `.claude/settings.json` — корректный JSON по схеме настроек Claude Code: запрет чтения `.env` и
   `data/`, подтверждение человека для `git push`, `npm run seed`, `docker`, `ssh`.
6. Последний шаг промпта — «проверь комплект на себе» на задаче «добавить в профиль куратора группы».
   Куратор уже показывается в профиле — учти это в ответе: что прочитаешь, какие инварианты
   касаются, какую команду вызовешь, чем закончишь, и чего в комплекте не хватило (допиши).

**Ответ:** Сделано (таблица файлов: создан / изменён, строк) / Что исправлено при сверке (было → стало,
с источником) / Как проверено / Не проверено / Предложения основному агенту.
