# iPhone Safari в симуляторе iOS, 22 ноября

**Что это.** Проверка пункта 10 рецензии в Safari на iPhone SE (3-го поколения), iOS 18.1 — в **симуляторе**
Xcode на Mac, а не на настоящем телефоне. Сервер — локальный, с демо-кабинетами (`DEMO_SANDBOXES=1`),
на свежей временной базе; симулятор обращается к нему по `localhost`. Снимки сделаны 22 ноября около 01:40–01:50 МСК
инструментом симулятора, без обработки.

Готовую электронную справку для проверки подготовили через API этого же сервера: вход Алины, заявка,
затем деканат в том же кабинете — «В работе» и «Готово». Дальше всё — касаниями в Safari.

**Оговорки.**
- Это симулятор: скорость, сеть, жесты и настоящая клавиатура телефона в нём не проверяются.
  Android Chrome и проход с VoiceOver или TalkBack не делались.
- Первая попытка набрать текст вставкой через буфер обмена симулятора дала искажённую кириллицу («Ӏ -њ–А…»):
  буфер инструмента передал текст не в той кодировке. Поле приняло то, что пришло; текст стёрт и набран
  касаниями по экранной клавиатуре — снимок 05.
- Перед снимком 02 страница открыта заново полной загрузкой: уже открытая вкладка держала стили,
  загруженные до перезапуска локального сервера.
