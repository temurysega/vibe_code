# Состояние до текущей доработки

Эти файлы скопированы из `docs/evidence/final/` перед текущим изменением интерфейса.
Это сохранённые снимки предыдущего локального прогона, а не вновь снятые экраны и
не изображения раннего этапа разработки. Его время, версия и SHA-256 исходников
указаны в приложенном `run-summary.json`.

В текущей итерации проверяются компактный обзор дисциплин и фильтр учебных рисков,
приоритет учебных разделов в навигации и высота карточек главной. Результат после
изменений сохраняется в `../final/`. Изображения вымышленных диалогов находятся
отдельно, в `../dialogue-illustrations/`, с указанием их происхождения.
